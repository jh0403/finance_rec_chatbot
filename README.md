# FinanFit — 맞춤 예금 추천 & AI 상담

회원의 **나이 · 투자성향 · 직업 · 소득**을 바탕으로 정기예금 3개를 추천하고,
OpenAI 기반 챗봇이 상품 상담을 해 주는 Flask 웹 서비스입니다.
화면 디자인은 하나은행 톤앤매너(하나 그린 `#008485`, '손님' 호칭)를 따릅니다.

```
kndaweb/
├── main.py              # Flask 서버 (인증 · 추천 · 챗봇 API)
├── .env                 # OPENAI_API_KEY, OPENAI_MODEL, SECRET_KEY
├── requirements.txt     # flask, openai, python-dotenv
├── users.db             # 회원정보 SQLite (첫 실행 시 자동 생성)
├── static/
│   ├── css/hana.css     # 공통 스타일 (색상 토큰, GNB, 버튼, 폼, 챗봇 버튼)
│   ├── logo.png         # 상단 로고
│   ├── bot.png          # 챗봇 아이콘
│   ├── 예금목록.csv      # 금융상품 데이터 (정기예금 100개)
│   └── uploads/         # 회원 프로필 사진 (가입 시 자동 생성)
└── templates/
    ├── login.html       # 로그인
    ├── signup.html      # 회원가입
    ├── main.html        # 맞춤 추천 상품 TOP 3
    └── chatbot.html     # AI 상품 상담 (ChatGPT 스타일)
```

## 실행 방법

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

브라우저에서 http://localhost:5000 접속 → 회원가입 → 로그인 순서로 사용합니다.

### `.env`

| 키 | 설명 | 기본값 |
|---|---|---|
| `OPENAI_API_KEY` | OpenAI API 키 (챗봇에 필요) | 없음 |
| `OPENAI_MODEL` | 챗봇 모델 | `gpt-4o-mini` |
| `SECRET_KEY` | 로그인 세션 암호화 키 | `dev-secret-change-me` |

- `.env`는 **요청마다 다시 읽기** 때문에 키나 모델을 바꿔도 서버를 재시작할 필요가 없습니다.
- `.env`에는 API 키가 들어 있으니 Git 등에 올리지 마세요.

## main.py

하나의 파일에 서버 전체가 들어 있으며, 위에서부터 다음 순서로 구성됩니다.

### 1. 설정 · OpenAI 클라이언트

| 이름 | 역할 |
|---|---|
| `DB_PATH` | 회원 DB 경로 (`users.db`) |
| `PRODUCTS_CSV` | 상품 CSV 경로 (`static/예금목록.csv`) |
| `UPLOAD_DIR` | 프로필 사진 저장 폴더 (`static/uploads`) |
| `get_openai()` | `.env`를 다시 읽어 OpenAI 클라이언트를 돌려줌 (키가 없으면 `None`) |
| `openai_model()` | 사용할 모델 이름 |

> `load_dotenv(override=True)`를 쓰는 이유: Flask 디버그 리로더의 부모 프로세스가
> 빈 키 값을 자식에게 물려주면, 기본 설정에서는 `.env`의 실제 키가 무시되기 때문입니다.

### 2. 회원가입 선택지

`GENDERS`, `RISK_LEVELS`(5단계 투자성향), `JOBS`(8개 직업), `INCOME_OPTIONS`(6개 연소득 구간).
연소득은 구간의 대표값(만원 단위 정수, 예: `3000` = 2천만~4천만원)으로 저장합니다.
선택지를 바꾸면 회원가입 화면과 검증 로직에 함께 반영됩니다.

### 3. 회원 DB (SQLite)

`init_db()`가 서버 시작 시 `users` 테이블을 만듭니다.

| 컬럼 | 내용 |
|---|---|
| `username` | 아이디 (영문·숫자·`_` 4~20자, 중복 불가) |
| `password_hash` | 비밀번호 해시 (`werkzeug.security`) |
| `name`, `email`, `age`, `gender` | 기본 정보 |
| `risk`, `job`, `income` | 추천에 쓰는 정보 |
| `profile_image` | `static/uploads/` 안의 파일명 (없으면 `NULL`) |

`login_required` 데코레이터는 로그인하지 않은 요청을 로그인 화면으로 보내고
(`/api/*`는 401 JSON), 로그인한 사용자를 `g.user`에 담습니다.

### 4. 상품 불러오기 — `load_products()`

`예금목록.csv`를 읽어 상품 목록(dict 리스트)을 만듭니다.
파일 수정 시간을 기억해 두었다가 **CSV가 바뀌면 자동으로 다시 읽습니다.**

CSV에는 연령·직업·투자성향 컬럼이 없기 때문에, 상품명 · 가입대상 · 가입방법 ·
상세정보(우대조건)에서 정보를 뽑아냅니다.

| 함수 | 하는 일 |
|---|---|
| `_core_detail()` | `상세정보전체`에서 네이버 메뉴·광고·세후 계산기 부분을 제거 |
| `_conditions()` | `조건별` 영역에서 우대조건 목록 추출 |
| `_benefit_lines()` | 카드에 보여줄 우대조건 3줄 (`조건 +0.3%p` 형태 우선) |
| `_min_amount()` | 가입금액 문구 → 최소 금액(만원) (`1백만원` → 100) |
| `_tags()` | 상품 특징 태그 부여 (아래 표) |

| 태그 | 판단 기준 (요약) | 표시 문구 |
|---|---|---|
| `pension` / `pension_bonus` | 상품명에 연금·골든·시니어 / 우대조건에 연금 수령 | 연금 손님 전용 / 연금 수령 우대 |
| `first` | 첫거래·첫만남 등 | 첫 거래 우대 |
| `salary` | 주거래·급여 | 주거래·급여 우대 |
| `business` | 가입대상에 개인사업자 포함 | 개인사업자 가입 가능 |
| `monthly` / `prepaid` | 월이자·매월 / 이자먼저·선이자 | 매월 이자 지급 / 이자 먼저 지급 |
| `variable` | 변동금리, 회전·연동·실세 | 회전·변동금리 |
| `flexible` | 자유만기·중도해지·내맘대로 | 자유만기·중도해지 유리 |
| `special` | 특판 | 특판 |
| `premium` / `small` | 최소 500만원 이상·고단위 / 최소 10만원 이하 | 고액 예치 / 소액 가입 |
| `digital_only` | 영업점 없이 비대면 전용, 인터넷전문은행 | 비대면 전용 |
| `simple` | 최고금리 − 기본금리 ≤ 0.1%p | 우대조건 없음 |

가입대상에 `만 N세 이상`이 있으면 `age_min`으로 저장해 그보다 어린 손님에게는 추천하지 않습니다.

### 5. 추천 — `recommend(user, products, n=3)`

```
점수 = 기본금리 × wb + 최고금리 × wm + 가산점 합계
```

- **투자성향별 금리 가중치** (`RISK_WEIGHTS`): 안정형 `(2.0, 0.5)` → 공격투자형 `(0.3, 2.2)`.
  안정형일수록 조건 없이 받는 기본금리를, 공격형일수록 최고금리를 중시합니다.
- **가산점**
  - 투자성향: 안정형은 고정금리·우대조건 없음, 위험중립형은 회전·연동형, 적극·공격형은 자유만기·특판
  - 나이: 30세 미만은 첫 거래·비대면, 50세 이상은 연금·월이자 (50세 미만은 연금 상품 감점)
  - 직업: 직장인·공무원·전문직은 급여이체, 자영업·프리랜서는 개인사업자, 은퇴자는 연금·월이자, 학생은 소액 가입
  - 소득: 2천만원 미만은 소액 가입, 8천만원 이상은 고액 예치
- 같은 은행 상품이 몰리지 않도록 **은행당 1개**씩 상위 3개를 고릅니다.
- 점수를 올린 항목은 카드의 추천 이유 태그(`reasons`, 최대 3개)로 표시됩니다.

추천 기준을 바꾸려면 `RISK_WEIGHTS`와 `recommend()` 안의 `add(조건, 점수, 이유)` 줄을 수정하면 됩니다.

### 6. 라우트

| 경로 | 메서드 | 설명 | 템플릿 |
|---|---|---|---|
| `/` | GET | 로그인 상태에 따라 `/main` 또는 `/login`으로 이동 | — |
| `/login` | GET, POST | 로그인 | `login.html` |
| `/logout` | GET | 세션 삭제 후 로그인 화면으로 | — |
| `/signup` | GET, POST | 회원가입 (입력 검증 + 프로필 사진 저장) | `signup.html` |
| `/main` | GET | 맞춤 추천 TOP 3 (로그인 필요) | `main.html` |
| `/chatbot` | GET | AI 상담 화면 (로그인 필요, `?q=질문`으로 자동 질문 가능) | `chatbot.html` |
| `/api/chat` | POST | 챗봇 응답 스트리밍 (로그인 필요) | — |

프로필 사진이 5MB를 넘으면 413 핸들러가 안내 메시지와 함께 회원가입 화면으로 돌려보냅니다.

### 7. 챗봇 API — `/api/chat`

- 요청: `{"messages": [{"role": "user" | "assistant", "content": "..."}]}` (최근 20개, 각 4,000자까지 사용)
- 응답: `text/plain` 스트리밍 (OpenAI 응답을 토큰 단위로 그대로 전달)
- 키가 없으면 `503`과 안내 메시지를 돌려줍니다.

`_system_prompt()`가 매 요청마다 다음 내용을 시스템 프롬프트로 만듭니다.

1. 손님 정보 (이름 · 나이 · 성별 · 투자성향 · 직업 · 연소득)
2. 상품 100개 요약 (최고금리 순, 추천 TOP 3에는 `★` 표시, 특징 태그 포함)
3. 상세정보 (기간별 금리 · 우대조건): **추천 TOP 3** + `_mentioned()`가 질문에서 찾은 상품
   (`정기예금`처럼 흔한 이름은 은행명이 함께 있어야 인식)
4. 상담 원칙 (목록 안의 상품만 추천, 금리 지어내지 않기, 데이터 기준일 안내 등)

### css/hana.css

- **색상 토큰** (`:root`): `--hana`(#008485 하나 그린), `--hana-dark`, `--hana-deep`, `--hana-mint`,
  `--hana-light`, `--hana-tint`, `--point`(#e5003f, 강조용 레드), 글자·선·배경 색
- **공통 컴포넌트**: `.gnb`(상단 바), `.btn-primary` / `.btn-outline`, `.input` / `.select`,
  `.flash`(알림), `.avatar`, `.chat-fab`(오른쪽 아래 챗봇 버튼), `.footer`
- 화면별 스타일은 각 템플릿의 `<style>` 안에 있습니다.

### 로고 · 챗봇 아이콘 표시 방식

두 이미지 모두 주변 여백이 넓어서, 원본은 그대로 두고 CSS `background-size`로 가운데만 잘라 보여줍니다.

```css
.logo     { aspect-ratio: 4 / 1; background: url(logo.png) center / 152% auto; }
.bot-icon { border-radius: 50%; background: #fff url(bot.png) center / 333% auto; }
```

이미지를 여백 없는 파일로 바꾸면 이 비율(`152%`, `333%`)도 `100%`에 가깝게 조정해야 합니다.
두 파일이 각각 3~4MB라 첫 로딩이 느릴 수 있으니, 같은 이름으로 압축해 두는 것을 권장합니다.

### 예금목록.csv

네이버페이 예적금 금리정보를 수집한 정기예금 100개(18개 금융사)입니다. 인코딩은 UTF-8입니다.

| 컬럼 | 사용처 |
|---|---|
| `금융사`, `상품명` | 카드 제목, 챗봇 목록 |
| `최고금리_숫자`, `기본금리_숫자` | 금리 표시 · 추천 점수 (비어 있으면 `최고금리`, `기본금리` 사용) |
| `가입기간`, `가입금액`, `가입방법`, `가입대상` | 카드 정보, 태그 · 최소금액 · 최소나이 추출 |
| `이자지급` | 선이자 태그 |
| `상세URL` | 카드의 "상품 상세 보기" 링크, 상품 ID |

같은 컬럼 구조로 파일을 교체하면 서버 재시작 없이 바로 반영됩니다.

> `static/` 안의 파일은 `/static/예금목록.csv` 주소로 누구나 내려받을 수 있습니다.

## templates/

모든 템플릿은 Pretendard 폰트(jsDelivr)와 `css/hana.css`를 불러오며, 모바일 폭에서도 깨지지 않도록 반응형으로 작성되어 있습니다.

### login.html

- 왼쪽: 하나 그린 그라데이션 브랜드 영역 (로고, "손님의 내일을 함께 설계합니다")
- 오른쪽: 아이디 · 비밀번호 로그인 폼, 회원가입 버튼, 보안 안내
- **아이디 저장**은 브라우저 `localStorage`(`finanfit_saved_id`)에 저장
- 비밀번호 보기/숨기기 토글
- 서버 변수: `username`(실패 시 입력값 유지), flash 메시지

### signup.html

세 단계 카드로 구성된 회원가입 폼 (`multipart/form-data`로 전송).

1. **로그인 정보**: 아이디, 비밀번호, 비밀번호 확인 (일치 여부 실시간 표시)
2. **기본 정보**: 프로필 사진(미리보기, 5MB 제한), 이름, 이메일, 나이, 성별
3. **투자 · 소득 정보**: 투자성향(설명이 붙은 5단계 선택), 직업, 연소득 구간

- 서버 변수: `form`(오류 시 입력값 유지), `genders`, `risks`, `jobs`, `incomes`
- 검증은 서버(`_validate_signup`)에서 다시 하며, 오류는 상단 flash 메시지로 표시

### main.html

- 상단 GNB: 로고, 메뉴(맞춤 추천 / AI 상담), 프로필 사진 · 이름, 로그아웃
- 인사 영역: 프로필, 나이 · 투자성향 · 직업 · 연소득 태그
- **추천 TOP 3 카드**: 금융사 · 특판 배지, 상품명, 설명, 최고/기본 금리, 가입기간 · 금액 · 방법 · 대상 · 금리유형,
  우대조건, 추천 이유 태그, "AI 상담사에게 물어보기"(`/chatbot?q=은행 상품명 ...`), "상품 상세 보기 ↗"
- AI 상담 안내 배너, 오른쪽 아래 **챗봇 플로팅 버튼**(`bot.png`)
- 서버 변수: `user`, `products`(추천 결과), `total`(전체 상품 수), `updated`(데이터 기준일)
- `avatar()` 매크로: 프로필 사진이 없으면 이름 첫 글자로 표시

### chatbot.html

ChatGPT 첫 화면처럼 단순한 상담 화면입니다.

- **첫 화면**: 챗봇 아이콘, "OOO 손님, 무엇을 도와드릴까요?", 입력창, 추천 질문 4개
- **대화 화면**: 손님 메시지는 오른쪽 말풍선, 답변은 왼쪽(아이콘 + 본문), 입력창은 하단 고정
- 답변을 **실시간 스트리밍**으로 출력하고 Markdown(표 · 목록 등)으로 렌더링
  (`marked` + `DOMPurify`, CDN을 못 불러오면 일반 텍스트로 표시)
- `Enter` 전송, `Shift+Enter` 줄바꿈, 한글 조합 중 Enter는 무시
- 응답 중에는 전송 버튼이 **중지** 버튼으로 바뀜 (`AbortController`)
- 대화 내용은 `sessionStorage`에 저장되어 새로고침해도 유지 (탭을 닫으면 삭제), "새 상담" 버튼으로 초기화
- `?q=` 파라미터가 있으면 해당 질문을 자동으로 전송
- 서버 변수: `user`, `ai_ready`(API 키 설정 여부 — 없으면 경고 표시)

## 화면 흐름

```
/login ──(회원가입)──▶ /signup ──(가입 완료)──▶ /login
   │
   └─(로그인)──▶ /main ──(카드 버튼 · 챗봇 아이콘)──▶ /chatbot ──▶ POST /api/chat ──▶ OpenAI
```
